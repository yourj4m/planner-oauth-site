# fweek website

The public pages of the [fweek](https://github.com/yourj4m/fweek) planner,
served by GitHub Pages at https://yourj4m.github.io/planner-oauth-site/:

- `/` what fweek is, and how it syncs through Google Drive or Nextcloud
- `/privacy/` privacy policy (the OAuth consent screen links here)
- `/terms/` terms of service

Plain HTML and one stylesheet; no build step.
